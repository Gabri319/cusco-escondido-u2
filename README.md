## 1. Descripción
Web para tours auténticos no masificados en Cusco (Waqrapukara, Ausangate, 7 Lagunas). Reserva directa por WhatsApp en soles - 900285723.

## 2. Tecnologías
- WordPress + Elementor (web final U2)
- HTML5 / CSS3 / JS (prototipo base en /index.html)
- Hosting: InfinityFree (wuaze.com) + GitHub Pages
- Git: Control de versiones

## 3. Secciones de la Web
- Inicio, Nosotros, Tours, Galería, Reservas
- Anclas: #inicio #nosotros #servicios #galeria #reserva
- Formulario conectado a WhatsApp
